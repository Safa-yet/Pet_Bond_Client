# 🐾 Pet Bond - Pet Adoption Platform

A full-stack Pet Adoption Platform where users can explore pets, submit adoption requests, and manage pet listings easily. This platform helps connect loving families with pets in need of a home.

## 🌐 Live Website

🔗 Live Link:https://pet-bond-indol.vercel.app

---

# 🚀 Features

- 🔐 JWT Authentication with HTTPOnly Cookies
- 🐶 Browse and search pets by species and name
- ❤️ Submit pet adoption requests
- 📋 Manage personal adoption requests
- 🏠 Add, update, and delete pet listings
- ✅ Pet owners can approve/reject requests
- 📱 Fully responsive for mobile, tablet, and desktop
- 🌙 Dark & Light mode support
- 🎨 Modern recruiter-friendly UI design

# 🔑 Environment Variables

Create a `.env.local` file:

```env
NEXT_PUBLIC_API_URL=your_backend_api_url
NEXT_PUBLIC_FIREBASE_API_KEY=your_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_domain
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_bucket
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
```

# ⚙️ Installation & Setup

Clone the project:

```bash
git clone https://github.com/your-username/pet-bond-client.git
```

Go to project directory:

```bash
cd pet-bond-client
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```
